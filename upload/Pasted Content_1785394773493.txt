============================================================================
LANDING FLARE TRAINER — full source bundle + integration instructions
============================================================================
This is the source for "Landing Flare Trainer," meant to become Mini-game 1
of the FlightCourse site (it currently shows as "Locked" on the dashboard,
next to Mini-game 3, "Pattern Perfect," which is already live). Everything
below the file markers (`=== FILE: path ===`) is real source code — create
each file at the given path. Read this whole instructions block before you
start; it tells you what's already correct, what was broken and has been
fixed, and what is genuinely still missing and needs to be written.

----------------------------------------------------------------------------
WHAT I FOUND
----------------------------------------------------------------------------
The uploaded files turned out to be pieces of TWO different, incompatible
builds of this same game, plus a shared `types.ts` that every file imports
from but that was missing entirely — nothing in this pile would have
compiled as-is. Specifically:

1. types.ts did not exist. flight-physics.ts, runway-canvas.tsx,
   hud-overlay.tsx, voice-coach.ts, audio-engine.ts (no dep), scoring-engine.ts,
   difficulty-scaler.ts, daily-challenge.ts, debrief-screen.tsx and
   progress-store.ts all do `import type {...} from "./types"`, and that file
   was never provided. It has been reconstructed below by cross-referencing
   the exact field names every one of those files actually reads and writes.
   It is written to be a drop-in match for all of them — see the comments
   inside types.ts for the reasoning. This was verified with `tsc --strict`
   against every plain .ts file in this bundle: zero type errors.

2. There were two competing implementations. One ("System A" — everything
   listed above) is the deeper, more complete build: a full aerodynamic C172
   model in flight-physics.ts, a five-dimension scoring rubric, a voice
   coach, procedural audio, screen-shake/particle "juice", and a radar-chart
   debrief screen. The other is a single self-contained file,
   `src/lib/aviation.ts`, with its own simpler physics/scoring/scenario
   system and its own local type definitions — it does not import "./types"
   and nothing in System A imports it either. It is a complete, unrelated
   draft. I have NOT wired it in. It's included at the very bottom of this
   bundle, clearly marked, only because its five hand-written scenario
   blurbs (Dusk Circuit, Calm Day, Night Landing, Crosswind, Morning Fog) are
   nicely-written flavor text you may want to mine for the difficulty/
   scenario picker copy. Do not import it or merge its types with types.ts —
   the two systems disagree on almost every shape (e.g. its LandingResult
   and FlightState are structurally different from System A's).

3. Several System A files expected slightly different field names than
   flight-physics.ts actually produces (case differences like `altitudeAGL`
   vs. the physics engine's `altitudeAgl`, and names like `airspeed` vs. the
   physics engine's `airspeedKias`). These files were all written
   defensively — they try several alias names before falling back to a
   default — which is exactly why this was fixable without touching their
   structure: I added the physics engine's real field names to each alias
   list. Every change is marked inline with a `// PATCHED:` comment
   explaining what was wrong. Nothing about their existing behavior or
   back-compat aliases was removed. Files touched: runway-canvas.tsx,
   hud-overlay.tsx, voice-coach.ts, debrief-screen.tsx.

4. difficulty-scaler.ts set `turbulence` to a string label (`'light'`,
   `'moderate'`...), but flight-physics.ts's `wxTurbulence()` reads it as a
   number 0..1 with no string parsing — the value would have been silently
   ignored at runtime. Fixed to emit a number, with the original label kept
   alongside as `turbulenceLabel` for any UI copy that wants it.

5. progress-store.ts (originally `progress-store-v2.ts`) imported the
   cross-game XP store from `@/lib/progress-store`. In the live FlightCourse
   codebase that store actually lives at `src/lib/store/progress-store.ts`
   (one extra path segment) — fixed. It also set a default `scenario` of the
   string `"normal"`, but `DifficultyLevel` is numeric (0..4) everywhere else
   in this bundle — fixed to a numeric default.

WHAT STILL NEEDS TO BE BUILT — you have every piece, but not the thing that
connects them. There is no top-level game component, no start/briefing
screen, and no page route anywhere in the source I was given.
----------------------------------------------------------------------------
Build a top-level orchestrator (e.g. `FlareTrainerGame.tsx`) that is a small
state machine: **briefing → flying → debrief**, matching the structure
Pattern Perfect already uses on this site so the two mini-games feel like
one product. Concretely, it needs to:

* BRIEFING screen: a difficulty picker driven by `difficulty-scaler.ts`
  (`computeDifficulty`, `weatherForDifficulty`, `difficultyLabel`) and a
  "Today's challenge" entry point via `daily-challenge.ts`
  (`getTodaysChallenge`, `isChallengeCompleted`). Model this screen after
  Pattern Perfect's StartScreen.tsx for visual consistency.

* FLYING screen: a requestAnimationFrame loop that, each frame:
  - reads pilot input (keyboard + on-screen touch controls, mirroring how
    Pattern Perfect's MobileControls.tsx handles touch) into a
    `FlightInputs` object;
  - calls `stepFlight(state, dt, inputs, weather)` from flight-physics.ts
    and stores the result in a ref (so `<RunwayCanvas stateRef={...}/>` and
    `<HudOverlay stateRef={...}/>` can read it without a React re-render
    every frame — both components already expect exactly this pattern);
  - calls `evaluatePhaseTransition`/`detectLanding` as needed;
  - calls `gameJuice.update(dt)` and composites `gameJuice.drawParticles()`
    / `drawOverlays()` on top of the canvas each frame, and calls
    `gameJuice.triggerTouchdown(quality, point)` at touchdown;
  - calls `voiceCoach.speak(callout.text, callout.priority)` whenever
    `getCoachCallout()` returns non-null;
  - calls the matching `audioEngine.play...()` methods at touchdown
    (`playTireSqueal`/`playThud`), stall entry/exit
    (`playStallHorn`/`stopStallHorn`), and crash (`playExplosion`);
  - owns the GUMPS checklist as its own small piece of UI state (tap-to-check
    during the downwind leg) and merges it into the object passed to
    `<HudOverlay/>` as `state.gumps` — nothing else in this bundle sets that
    field, `hud-overlay.tsx` just reads it defensively;
  - samples telemetry a few times per second (NOT every physics substep)
    via `sampleTelemetry()`, pushing into a running array, and — while
    `state.phase` is `"downwind" | "abeam" | "base" | "final"` — also pushes
    `airspeedKias` into `approachSpeeds[]`, `glideslopeErrorDeg` into
    `glideslopeDeviations[]`, and `centerlineOffsetFt` into
    `approachCenterlineOffsets[]`. Capture `flareStartAltitude` once, the
    first frame `state.phase` becomes `"roundout"` or `"flare"`.

* On landing (phase becomes `"complete"` or `"crashed"`, or
  `detectLanding().landed`), assemble a `LandingResult` per the contract
  documented at the top of `types.ts` — the accumulated arrays above, the
  touchdown snapshot fields copied off the physics touchdown record

* Wire the "Play" action into the FlightCourse dashboard's Mini-game 1 card

----------------------------------------------------------------------------
KNOWN LIMITATIONS I DID NOT FIX (design decisions, not bugs — your call)
----------------------------------------------------------------------------
* `runwayLength`/`runwayWidth` in difficulty-scaler.ts and daily-challenge.ts
  are currently cosmetic for the actual flight: flight-physics.ts always
  simulates a FIXED 3,500 x 100 ft runway via its own `RUNWAY_LENGTH`/
  `RUNWAY_WIDTH` constants (used at the crash/rollout checks — search for
  those two constant names in flight-physics.ts). `scoreLanding()` *does*
  grade the touchdown zone against whatever `runwayLength` you put on
  `LandingResult`, so right now a "short field" scenario is scored as if the
  runway were shorter without the physics actually simulating a shorter
  runway. If you want short-field/wide-runway variety to really change the
  flying, thread `weather.runwayLength`/`runwayWidth` into those two
  constants inside `createInitialState`/`stepFlight` instead of the fixed
  numbers. Left as-is for now rather than guessing at a rebalance.
* `sTurns` and `glideslopeChasing` on `LandingResult` default to 0 unless the
  orchestrator computes them — a reasonable heuristic is counting sign
  changes in `bankDeg` (for S-turns) or in `glideslopeErrorDeg` (for
  chasing) across the approach, but this wasn't specified anywhere in the
  original source, so it's left as a documented gap rather than an invented
  number.
* `decrabError` is approximated as `|touchdownBankDeg|` — a reasonable
  proxy, not a true measured heading-vs-runway crab angle. Fine as a first
  pass; scoring-engine.ts only uses it when `crosswindComponent >= 3`.
* voice-coach.ts's glide-deviation callout thresholds (±0.12) were written
  against an unspecified unit scale. They now receive true degrees via
  `glideslopeErrorDeg` (a ±3° glideslope typically runs a degree or two of
  error before it's noticeably off). Playtest and retune the 0.12 constant
  if the "High"/"Low" callouts feel too twitchy or too lax.

  runwayLength: number;

/**
 * flight-physics.ts — Cessna 172S flight model for the Flare Trainer.
 * FlightCourse Academy.
 *
 * Design goals
 * ------------
 * 1. Skill transfer. Every number below is traceable to the C172S POH or to a
 *    hand-verified trim/climb/descent check (see PERFORMANCE VALIDATION notes).
 *    A student who learns to hold 65 KIAS on a 3-degree path here will hold it
 *    in MSFS or X-Plane.
 * 2. Determinism. Gusts and turbulence come from an LCG + Ornstein-Uhlenbeck
 *    process whose seed lives in the state, so a replay of the same inputs
 *    reproduces the same landing, byte for byte.
 * 3. Frame budget. No heap traffic inside the integrator: everything is local
 *    number scratch, and each call returns exactly one plain object literal
 *    (unavoidable given the immutable `stepFlight` contract). No arrays, no
 *    closures, no Math.random, no allocations in helpers.
 *
 * Coordinate frame (runway-local, feet)
 * -------------------------------------
 *   x : along the landing runway. x = 0 is the threshold, +x is the landing
 *       direction (rollout direction). Runway is RUNWAY_LENGTH long.
 *   y : lateral, +y is RIGHT of the landing direction. y = 0 is centerline.
 *   altitudeAgl : feet above the runway surface.
 *   heading : degrees TRUE. `runwayHeading` (default 0 / Runway 36) maps true
 *       heading to the local frame, so relative heading 0 = aligned to land.
 *   Left-hand traffic: downwind sits at negative y, base is flown on 090-rel.
 *
 * types.ts contract
 * -----------------
 * The exact field list of `FlightState` lives in ./types. This module works
 * against the fully-documented `PhysicsState` shape below and casts at the
 * public boundary, so it compiles against any structurally-compatible
 * `FlightState`. If your `FlightPhase` union uses different string literals,
 * change ONLY the PHASE table near the top of this file.
 */

import type {
  FlightState,
  FlightPhase,
  TelemetryFrame,
  WeatherConditions,
} from './types';

/* ==========================================================================
 * 1. PILOT INPUTS
 * ========================================================================== */

export interface FlightInputs {
  /** Elevator. -1 = full forward (nose down), +1 = full aft (nose up). */
  pitchInput: number;
  /** Aileron. -1 = full left, +1 = full right. */
  rollInput: number;
  /** Throttle. 0 = idle (~700 RPM), 1 = full (~2700 RPM). */
  throttleInput: number;
  /** Commanded flap handle position in degrees: 0, 10, 20 or 30. */
  flapTarget: number;
  /** Carburettor heat. ON costs ~9% power and ~75 RPM. */
  carbHeat: boolean;
  /** Rudder. -1 = full left, +1 = full right. */
  rudderInput: number;
  /** Optional wheel brakes, 0..1. Ignored in flight. */
  brakeInput?: number;
}

/* ==========================================================================
 * 2. PHASE TABLE  (edit here if your FlightPhase literals differ)
 * ========================================================================== */

const PHASE = {
  downwind: 'downwind' as unknown as FlightPhase,
  abeam: 'abeam' as unknown as FlightPhase,
  base: 'base' as unknown as FlightPhase,
  final: 'final' as unknown as FlightPhase,
  roundout: 'roundout' as unknown as FlightPhase,
  flare: 'flare' as unknown as FlightPhase,
  touchdown: 'touchdown' as unknown as FlightPhase,
  rollout: 'rollout' as unknown as FlightPhase,
  complete: 'complete' as unknown as FlightPhase,
  goAround: 'go-around' as unknown as FlightPhase,
  crashed: 'crashed' as unknown as FlightPhase,
};

/* ==========================================================================
 * 3. AIRCRAFT + ENVIRONMENT CONSTANTS  (Cessna 172S, 2300 lb gross)
 * ========================================================================== */

const G = 32.174; // ft/s^2
const KT_TO_FPS = 1.68781;
const FPS_TO_KT = 1 / KT_TO_FPS;
const FPM_PER_FPS = 60;
const DEG = Math.PI / 180;
const RAD = 180 / Math.PI;
const RHO_SL = 0.0023769; // slug/ft^3, ISA sea level

const WEIGHT = 2300; // lb
const MASS = WEIGHT / G; // slug
const WING_AREA = 174; // ft^2
const WING_SPAN = 36.083; // ft
const ASPECT_RATIO = (WING_SPAN * WING_SPAN) / WING_AREA; // 7.483
const OSWALD_E = 0.75;
const K_INDUCED = 1 / (Math.PI * ASPECT_RATIO * OSWALD_E); // 0.0567

// Lift curve. CL = CL0 + CL_ALPHA * alphaDeg + dCL(flaps), capped at CLmax.

/* ==========================================================================
 * 5. SMALL PURE HELPERS (all allocation-free)
 * ========================================================================== */

function clamp(v: number, lo: number, hi: number): number {
  return v < lo ? lo : v > hi ? hi : v;
}

function num(v: unknown, fallback: number): number {
  return typeof v === 'number' && Number.isFinite(v) ? v : fallback;
}

/** Wrap to [0, 360). */
function wrap360(deg: number): number {
  let d = deg % 360;
  if (d < 0) d += 360;
  return d;
}

/** Wrap to (-180, 180]. */
function wrap180(deg: number): number {
  let d = (deg + 180) % 360;
  if (d < 0) d += 360;
  return d - 180;
}

/** First-order lag factor for a time constant tau over dt. */
function lagAlpha(dt: number, tau: number): number {
  return tau <= 0 ? 1 : 1 - Math.exp(-dt / tau);
}

/** Snap a flap handle request to a legal detent. */
export function snapFlapDetent(deg: number): number {
  if (deg < 5) return 0;
  if (deg < 15) return 10;
  if (deg < 25) return 20;
  return 30;
}

/** Published stall speed, KIAS, interpolated between detents. */
export function stallSpeedForFlaps(flapsDeg: number): number {
  const f = clamp(flapsDeg, 0, 30);
  if (f <= 10) return VS_F0 + ((VS_F10 - VS_F0) * f) / 10;
  if (f <= 20) return VS_F10 + ((VS_F20 - VS_F10) * (f - 10)) / 10;
  return VS_F20 + ((VS_F30 - VS_F20) * (f - 20)) / 10;
}

/**
 * CLmax derived directly from the published stall speed, so the model stalls
 * exactly where the POH says it does:  CLmax = W / (q_stall * S).
 * Full flaps -> 2.44, clean -> 1.69.
 */
export function clMaxForFlaps(flapsDeg: number): number {
  const vs = stallSpeedForFlaps(flapsDeg) * KT_TO_FPS;
  return WEIGHT / (0.5 * RHO_SL * vs * vs * WING_AREA);
}

/** Flap lift increment at zero alpha. */
function flapLiftIncrement(flapsDeg: number): number {
  const f = clamp(flapsDeg, 0, 30);
  if (f <= 10) return (0.35 * f) / 10;
  if (f <= 20) return 0.35 + (0.3 * (f - 10)) / 10;
  return 0.65 + (0.25 * (f - 20)) / 10; // 30 deg -> 0.90
}

/** Flap parasite-drag increment. */
function flapDragIncrement(flapsDeg: number): number {
  const f = clamp(flapsDeg, 0, 30);
  if (f <= 10) return (0.007 * f) / 10;
  if (f <= 20) return 0.007 + (0.017 * (f - 10)) / 10;
  return 0.024 + (0.031 * (f - 20)) / 10; // 30 deg -> 0.055
}

/**
 * Stalling angle of attack. Falls monotonically with flap extension:
 * 16.9 / 15.5 / 15.4 / 15.1 degrees for 0 / 10 / 20 / 30.
 */
export function stallAlphaForFlaps(flapsDeg: number): number {
  return (clMaxForFlaps(flapsDeg) - CL0 - flapLiftIncrement(flapsDeg)) / CL_ALPHA;
}

/** Highest flap setting legal at this indicated airspeed. */
function flapLimitForSpeed(kias: number): number {
  if (kias > VFE_10) return 0;
  if (kias > VFE_FULL) return 10;
  return 30;
}

/** ISA density ratio for a density altitude in feet. */
function densityRatioForAltitude(densityAlt: number): number {
  const t = 1 - 6.87535e-6 * densityAlt;
  return t <= 0 ? 0.05 : Math.pow(t, 4.2561);
}

/* ==========================================================================
 * 6. WEATHER NORMALISATION
 * Tolerates several plausible field spellings in WeatherConditions so the
 * engine never divides by undefined.
 * ========================================================================== */

function wxWindSpeed(w: WeatherConditions): number {
  const o = w as unknown as Record<string, unknown>;
  return Math.max(
    0,
    num(o.windSpeed, num(o.windSpeedKts, num(o.windKts, num(o.wind, 0)))),
  );
}

/** Direction the wind is coming FROM, degrees true (met convention). */
function wxWindDirection(w: WeatherConditions): number {
  const o = w as unknown as Record<string, unknown>;
  return wrap360(
    num(o.windDirection, num(o.windDir, num(o.windDirectionDeg, num(o.windHeading, 0)))),
  );
}

/** Peak gust speed in knots (total, not the increment). */
function wxGustSpeed(w: WeatherConditions): number {
  const o = w as unknown as Record<string, unknown>;
  return Math.max(
    0,
    num(o.gustSpeed, num(o.windGust, num(o.gustKts, num(o.gusts, 0)))),
  );
}

/** 0 = glass smooth, 1 = white knuckles. */
function wxTurbulence(w: WeatherConditions): number {
  const o = w as unknown as Record<string, unknown>;
  return clamp(num(o.turbulence, num(o.turbulenceIntensity, num(o.turbulenceLevel, 0))), 0, 1);
}

function wxTemperatureC(w: WeatherConditions): number {
  const o = w as unknown as Record<string, unknown>;
  return num(o.temperature, num(o.temperatureC, num(o.oatC, num(o.oat, 15))));
}

function wxAltimeterInHg(w: WeatherConditions): number {
  const o = w as unknown as Record<string, unknown>;
  return num(o.altimeter, num(o.altimeterSetting, num(o.pressureInHg, num(o.qnh, 29.92))));
}

function wxFieldElevation(w: WeatherConditions): number {
  const o = w as unknown as Record<string, unknown>;
  return num(o.fieldElevation, num(o.elevation, num(o.airportElevation, 0)));
}

function wxRunwayHeading(w: WeatherConditions): number {
  const o = w as unknown as Record<string, unknown>;
  return wrap360(num(o.runwayHeading, num(o.runwayHdg, num(o.runwayCourse, 0))));
}

function wxSeed(w: WeatherConditions): number {
  const o = w as unknown as Record<string, unknown>;
  return num(o.seed, num(o.randomSeed, 0x5eed1e)) >>> 0;
}

/** Density altitude from field elevation, altimeter setting and OAT. */
function computeDensityAltitude(w: WeatherConditions): number {
  const fieldElev = wxFieldElevation(w);
  const pressureAlt = fieldElev + (29.92 - wxAltimeterInHg(w)) * 1000;
  const isaTemp = 15 - 0.0019812 * pressureAlt;
  return pressureAlt + 118.8 * (wxTemperatureC(w) - isaTemp);
}

/* ==========================================================================
 * 7. TURBULENCE: LCG + Ornstein-Uhlenbeck
 * ========================================================================== */

/** Advance the LCG. Returns the new state; caller keeps it in FlightState. */
function lcgNext(s: number): number {
  return (Math.imul(s, 1664525) + 1013904223) >>> 0;
}

/** Uniform 0..1 from an LCG state. */
function lcgUnit(s: number): number {
  return s / 4294967296;
}

/* ==========================================================================
 * 8. ENGINE MODEL
 * ========================================================================== */

/** Shaft power fraction of rated 180 hp for a given RPM. */
function powerFractionForRpm(rpm: number, carbHeat: boolean): number {
  const f = Math.pow(clamp(rpm, 0, RPM_MAX) / RPM_MAX, RPM_POWER_EXP);
  return clamp(carbHeat ? f * CARB_HEAT_POWER : f, 0, 1);
}

/**
 * Propeller thrust, lb. Momentum-limited at low speed (static thrust ceiling)
 * and power-limited at high speed (eta * P / V). Validated points at sea level:
 *   2700 RPM, clean, 74 kt  -> ~762 fpm climb (POH 730)
 *   2700 RPM, flaps 30, 65  -> ~270 fpm climb
 *   1500 RPM, flaps 20, 65  -> ~420 fpm descent (pattern power)
 *   idle,     flaps 30, 65  -> ~1020 fpm descent
 *   idle,     clean,   65   -> ~10:1 glide (POH 9.1:1)
 */
function propellerThrust(powerFraction: number, tasFps: number, densityRatio: number): number {
  const staticT = STATIC_THRUST_MAX * Math.pow(powerFraction, 0.75) * densityRatio;
  const shaftFtLbS = RATED_HP * powerFraction * 550 * densityRatio;
  const v = Math.max(tasFps, 12); // avoid the 1/0 at a standstill
  const powerLimited = (shaftFtLbS * PROP_ETA_MAX) / v;
  return Math.min(staticT, powerLimited);
}

/* ==========================================================================
 * 9. PUBLIC: createInitialState
 * ========================================================================== */

/**
 * Player starts established on the downwind leg: 1000 ft AGL, 90 KIAS,
 * flaps up, 2300 RPM, wings level, parallel to the runway on the left-traffic
 * (negative y) side, still upwind of the abeam point.
 */
export function createInitialState(weather: WeatherConditions): FlightState {
  const runwayHeading = wxRunwayHeading(weather);
  const fieldElevation = wxFieldElevation(weather);
  const densityAltitude = computeDensityAltitude(weather);
  const densityRatio = densityRatioForAltitude(densityAltitude + PATTERN_ALTITUDE);

  const kias = 90;
  const ktas = kias / Math.sqrt(Math.max(densityRatio, 0.2));
  const flaps = 0;

  // Trim alpha for level flight at 90 KIAS clean.
  const tasFps = ktas * KT_TO_FPS;
  const q = 0.5 * RHO_SL * densityRatio * tasFps * tasFps;
  const clReq = WEIGHT / Math.max(q * WING_AREA, 1);
  const alpha = clamp((clReq - CL0 - flapLiftIncrement(flaps)) / CL_ALPHA, -4, 12);

  // Downwind: reciprocal heading, runway off the left wing.
  const headingDeg = wrap360(runwayHeading + 180);

  const windSpeed = wxWindSpeed(weather);
  const windRel = (wxWindDirection(weather) - runwayHeading) * DEG;

  const s: PhysicsState = {
    time: 0,
    frame: 0,
    phase: PHASE.downwind,
    phaseTime: 0,
    rngState: (wxSeed(weather) ^ 0x9e3779b9) >>> 0,

    x: 4000, // ~3700 ft of downwind before the abeam point
    y: -DOWNWIND_OFFSET,
    altitudeAgl: PATTERN_ALTITUDE,
    fieldElevation,
    altitudeMsl: fieldElevation + PATTERN_ALTITUDE,

    airspeedKias: kias,
    airspeedKtas: ktas,
    groundSpeedKt: Math.sqrt(
      Math.pow(-tasFps - windSpeed * KT_TO_FPS * Math.cos(windRel), 2) +
        Math.pow(windSpeed * KT_TO_FPS * Math.sin(windRel), 2),
    ) * FPS_TO_KT,
    verticalSpeedFpm: 0,
    groundTrackDeg: wrap360(
      runwayHeading +
        Math.atan2(
          -windSpeed * KT_TO_FPS * Math.sin(windRel),
          -tasFps - windSpeed * KT_TO_FPS * Math.cos(windRel),
        ) * RAD,
    ),

    pitchDeg: alpha,
    bankDeg: 0,
    headingDeg,
    alphaDeg: alpha,
    betaDeg: 0,
    flightPathDeg: 0,

    flapsDeg: flaps,
    flapTargetDeg: flaps,
    rpm: RPM_CRUISE,
    throttle: (RPM_CRUISE - RPM_IDLE) / (RPM_MAX - RPM_IDLE),
    carbHeat: false,
    powerFraction: powerFractionForRpm(RPM_CRUISE, false),
    thrustLb: 0,
    liftLb: WEIGHT,
    dragLb: 0,
    loadFactor: 1,

    stalled: false,
    stallWarning: false,
    stallSpeedKias: stallSpeedForFlaps(flaps),
    overspeed: false,
    onGround: false,
    inGroundEffect: false,

    runwayHeading,
    distanceToThreshold: -4000,
    glideslopeErrorFt: 0,
    glideslopeErrorDeg: 0,
    centerlineOffsetFt: -DOWNWIND_OFFSET,
    crosswindComponentKt: windSpeed * Math.sin(windRel),
    headwindComponentKt: windSpeed * Math.cos(windRel),

    densityAltitude,
    densityRatio,
    gustLongitudinal: 0,
    gustVertical: 0,
    gustLateral: 0,

    touchedDown: false,
    touchdownVS: 0,
    touchdownPoint: 0,
    touchdownSpeedKias: 0,
    touchdownCenterlineOffset: 0,
    touchdownPitchDeg: 0,
    touchdownBankDeg: 0,
    bounceCount: 0,
    bounced: false,
    crashed: false,
    crashReason: '',
    landingComplete: false,
  };

  return s as unknown as FlightState;
}

/* ==========================================================================
 * 10. PUBLIC: stepFlight
 * ========================================================================== */

/**
 * Integrate one frame. Pure: never mutates `state`, returns a fresh plain
 * object. Internally uses only local number scratch (no arrays, no temp
 * objects, no closures), and sub-steps at 50 Hz so a dropped frame stays
 * stable instead of exploding the alpha loop.
 */
export function stepFlight(
  state: FlightState,
  dt: number,
  inputs: FlightInputs,
  weather: WeatherConditions,
): FlightState {
  const s = state as unknown as PhysicsState;

  const frameDt = clamp(num(dt, 1 / 60), 0, DT_MAX);

  /* ---- pilot inputs, sanitised ---- */
  const pitchIn = clamp(num(inputs.pitchInput, 0), -1, 1);
  const rollIn = clamp(num(inputs.rollInput, 0), -1, 1);
  const throttleIn = clamp(num(inputs.throttleInput, 0), 0, 1);
  const rudderIn = clamp(num(inputs.rudderInput, 0), -1, 1);
  const brakeIn = clamp(num(inputs.brakeInput, 0), 0, 1);
  const carbHeat = inputs.carbHeat === true;
  const flapRequest = snapFlapDetent(num(inputs.flapTarget, s.flapsDeg));

  /* ---- environment (constant across the frame) ---- */
  const runwayHeading = s.runwayHeading;
  const windSpeedKt = wxWindSpeed(weather);
  const gustPeakKt = wxGustSpeed(weather);
  const turbulence = wxTurbulence(weather);
  const windRelRad = (wxWindDirection(weather) - runwayHeading) * DEG;
  // Wind velocity vector in the runway frame, ft/s. Wind FROM the runway
  // heading (windRel = 0) blows toward -x, i.e. a headwind on final.
  const windXFull = -windSpeedKt * KT_TO_FPS * Math.cos(windRelRad);
  const windYFull = -windSpeedKt * KT_TO_FPS * Math.sin(windRelRad);
  const headwindKt = windSpeedKt * Math.cos(windRelRad);
  const crosswindKt = windSpeedKt * Math.sin(windRelRad);
  const gustIncrementFps = Math.max(0, gustPeakKt - windSpeedKt) * KT_TO_FPS;
  const gustSigma = gustIncrementFps * 0.55 + turbulence * 9;

  const densityAltitude = s.densityAltitude;
  const stallHornSpeedFactor = 1 + STALL_HORN_MARGIN / VS_F30; // 1.20

  /* ---- working copies (locals: stack only) ---- */
  let time = s.time;
  let x = s.x;
  let y = s.y;
  let alt = s.altitudeAgl;
  let ktas = s.airspeedKtas;
  let gamma = s.flightPathDeg;
  let heading = s.headingDeg;
  let bank = s.bankDeg;
  let alpha = s.alphaDeg;
  let beta = s.betaDeg;
  let pitch = s.pitchDeg;
  let flaps = s.flapsDeg;
  let rpm = s.rpm;
  let rng = s.rngState;
  let gustU = s.gustLongitudinal;
  let gustW = s.gustVertical;
  let gustV = s.gustLateral;
  let onGround = s.onGround;
  let stalled = s.stalled;
  let bounceCount = s.bounceCount;
  let bounced = false;
  let crashed = s.crashed;
  let crashReason = s.crashReason;
  let touchedDown = s.touchedDown;
  let touchdownVS = s.touchdownVS;
  let touchdownPoint = s.touchdownPoint;
  let touchdownSpeed = s.touchdownSpeedKias;
  let touchdownOffset = s.touchdownCenterlineOffset;
  let touchdownPitch = s.touchdownPitchDeg;
  let touchdownBank = s.touchdownBankDeg;
  let landingComplete = s.landingComplete;

  // Per-frame outputs, filled by the last sub-step.
  let densityRatio = s.densityRatio;
  let kias = s.airspeedKias;
  let liftLb = s.liftLb;
  let dragLb = s.dragLb;
  let thrustLb = s.thrustLb;
  let loadFactor = s.loadFactor;
  let powerFraction = s.powerFraction;
  let vsFps = s.verticalSpeedFpm / FPM_PER_FPS;
  let groundSpeedKt = s.groundSpeedKt;
  let groundTrack = s.groundTrackDeg;
  let inGroundEffect = s.inGroundEffect;
  let stallWarning = s.stallWarning;
  let overspeed = s.overspeed;
  let stallSpeedKias = s.stallSpeedKias;

  const steps = frameDt <= 0 ? 0 : Math.max(1, Math.ceil(frameDt / SUBSTEP_MAX));
  const h = steps > 0 ? frameDt / steps : 0;

  for (let step = 0; step < steps; step++) {
    time += h;

    /* ---------------- atmosphere ---------------- */
    densityRatio = densityRatioForAltitude(densityAltitude + alt);
    const rho = RHO_SL * densityRatio;
    const sqrtSigma = Math.sqrt(Math.max(densityRatio, 0.2));

    /* ---------------- turbulence (OU process) ---------------- */
    if (gustSigma > 0.01) {
      const tauG = 2.5;
      const gainG = Math.sqrt((2 * h) / tauG);
      // 3-sample Irwin-Hall gaussian approximation, allocation-free.
      rng = lcgNext(rng);
      const a1 = lcgUnit(rng);
      rng = lcgNext(rng);
      const a2 = lcgUnit(rng);
      rng = lcgNext(rng);
      const a3 = lcgUnit(rng);
      const nU = (a1 + a2 + a3 - 1.5) * 2;
      rng = lcgNext(rng);
      const b1 = lcgUnit(rng);
      rng = lcgNext(rng);
      const b2 = lcgUnit(rng);
      rng = lcgNext(rng);
      const b3 = lcgUnit(rng);
      const nW = (b1 + b2 + b3 - 1.5) * 2;
      rng = lcgNext(rng);
      const c1 = lcgUnit(rng);
      rng = lcgNext(rng);
      const c2 = lcgUnit(rng);
      rng = lcgNext(rng);
      const c3 = lcgUnit(rng);
      const nV = (c1 + c2 + c3 - 1.5) * 2;

      gustU += (-gustU / tauG) * h + gustSigma * gainG * nU;
      gustW += (-gustW / tauG) * h + gustSigma * 0.7 * gainG * nW;
      gustV += (-gustV / tauG) * h + gustSigma * 0.7 * gainG * nV;
      // Gusts die out in the surface layer.
      const gustFade = alt < 30 ? 0.45 + (0.55 * alt) / 30 : 1;
      gustU = clamp(gustU, -gustSigma * 3, gustSigma * 3) * gustFade;
      gustW = clamp(gustW, -gustSigma * 2, gustSigma * 2) * gustFade;
      gustV = clamp(gustV, -gustSigma * 2, gustSigma * 2) * gustFade;
    } else {
      gustU *= 1 - lagAlpha(h, 1.5);
      gustW *= 1 - lagAlpha(h, 1.5);
      gustV *= 1 - lagAlpha(h, 1.5);
    }

    /* ---------------- wind gradient ---------------- */
    const windScale = alt < 50 ? 0.65 + (0.35 * alt) / 50 : 1;
    const windX = windXFull * windScale;
    const windY = windYFull * windScale;

    /* ---------------- flaps ---------------- */
    kias = ktas * sqrtSigma;
    const flapCeiling = flapLimitForSpeed(kias);
    const flapCommand = Math.min(flapRequest, Math.max(flapCeiling, 0));
    if (flaps < flapCommand) flaps = Math.min(flapCommand, flaps + FLAP_RATE * h);
    else if (flaps > flapCommand) flaps = Math.max(flapCommand, flaps - FLAP_RATE * h);

    /* ---------------- engine ---------------- */
    // Fixed-pitch prop: RPM also rises with airspeed at a given throttle.
    let rpmTarget = RPM_IDLE + throttleIn * (RPM_MAX - RPM_IDLE) + (kias - 65) * 2;
    if (carbHeat) rpmTarget -= CARB_HEAT_RPM;
    rpmTarget = clamp(rpmTarget, 550, 2750);
    rpm += (rpmTarget - rpm) * lagAlpha(h, ENGINE_TAU);
    powerFraction = powerFractionForRpm(rpm, carbHeat);

    /* ---------------- aerodynamics ---------------- */
    // Effective airspeed includes the longitudinal gust: a gust is felt first
    // as an airspeed excursion, which then propagates into lift and pitch.
    const tasFps = ktas * KT_TO_FPS;
    const vAirFps = Math.max(tasFps + gustU, 5);
    const q = 0.5 * rho * vAirFps * vAirFps;
    const qS = q * WING_AREA;
    const qRatio = clamp(qS / 2488, 0.25, 3); // 2488 = qS at 65 KIAS, SL

    const clMax = clMaxForFlaps(flaps);
    const dClFlap = flapLiftIncrement(flaps);
    const alphaStall = stallAlphaForFlaps(flaps);
    stallSpeedKias = stallSpeedForFlaps(flaps);

    /* ---- pitch: alpha-command with speed stability (self-trimming) ---- */
    const clTrim = clamp((WEIGHT / Math.max(Math.cos(bank * DEG), 0.4)) / Math.max(qS, 1), -0.4, clMax);
    const alphaTrim = clamp((clTrim - CL0 - dClFlap) / CL_ALPHA, -6, alphaStall - 0.4);
    const ctrlEff = stalled ? 0.35 : 1;
    let alphaTarget = alphaTrim + pitchIn * PITCH_AUTHORITY_DEG * ctrlEff;
    if (stalled) {
      // Stall break: the nose falls whether or not the pilot agrees.
      alphaTarget = Math.min(alphaTarget, alphaStall - 4.5);
    }
    if (onGround) {
      alphaTarget = clamp(alphaTarget, -2, 13);
    }
    alpha += (alphaTarget - alpha) * lagAlpha(h, stalled ? 0.7 : PITCH_TAU);
    // Vertical gust arrives as an instantaneous alpha change.
    const alphaGust = Math.atan2(gustW, Math.max(vAirFps, 20)) * RAD;
    const alphaEff = clamp(alpha + alphaGust, -12, 30);

    /* ---- lift coefficient with a smooth post-stall lapse ---- */
    let cl = CL0 + CL_ALPHA * alphaEff + dClFlap;
    let postStall = 0;
    if (alphaEff > alphaStall) {
      postStall = clamp((alphaEff - alphaStall) / 8, 0, 1);
      cl = clMax * (1 - 0.55 * postStall);
    } else if (cl > clMax) {
      cl = clMax;
    }
    // Sideslip spills a little lift.
    const absBeta = beta < 0 ? -beta : beta;
    cl *= 1 - 0.004 * absBeta;

    /* ---- ground effect: the source of the float ---- */
    let inducedFactor = 1;
    let geLift = 1;
    inGroundEffect = alt < GROUND_EFFECT_HEIGHT;
    if (inGroundEffect) {
      const geFrac = 1 - clamp(alt / GROUND_EFFECT_HEIGHT, 0, 1);
      inducedFactor = 1 - GROUND_EFFECT_DRAG_CUT * geFrac;
      geLift = 1 + GROUND_EFFECT_LIFT_GAIN * geFrac;
    }
    cl *= geLift;

    /* ---- drag ---- */
    let cd =
      CD0_CLEAN +
      flapDragIncrement(flaps) +
      CD_PROP_WINDMILL * (1 - powerFraction) +
      K_INDUCED * cl * cl * inducedFactor;
    cd += 0.0008 * absBeta * absBeta; // slip drag
    if (postStall > 0) cd += 0.09 * (alphaEff - alphaStall);

    liftLb = cl * qS;
    dragLb = cd * qS;
    thrustLb = propellerThrust(powerFraction, vAirFps, densityRatio);

    const gammaRad = gamma * DEG;
    const bankRad = bank * DEG;
    loadFactor = liftLb / WEIGHT;

    /* ---------------- stall bookkeeping ---------------- */
    const wasStalled = stalled;
    if (onGround) {
      stalled = false;
    } else if (wasStalled) {
      // Keep the stall latched until both AoA and airspeed have recovered.
      stalled = !(alphaEff < alphaStall - 2.5 && kias > stallSpeedKias * 1.03);
    } else {
      stalled = alphaEff > alphaStall || kias < stallSpeedKias * 0.97;
    }
    stallWarning =
      !onGround &&
      (kias < stallSpeedKias * stallHornSpeedFactor || alphaEff > alphaStall - 2);
    overspeed = kias > VNO;

    if (!onGround) {
      /* ================= AIRBORNE ================= */

      /* ---- longitudinal: dV/dt ---- */
      const vDot = (thrustLb - dragLb - WEIGHT * Math.sin(gammaRad)) / MASS;
      let tasFpsNew = tasFps + vDot * h;
      if (tasFpsNew < 8) tasFpsNew = 8;
      ktas = tasFpsNew * FPS_TO_KT;

      /* ---- vertical: flight path rotation ---- */
      const vForPath = Math.max(tasFpsNew, 25);
      const gammaDot =
        ((liftLb * Math.cos(bankRad) - WEIGHT * Math.cos(gammaRad)) / (MASS * vForPath)) * RAD;
      gamma = clamp(gamma + gammaDot * h, -35, 25);
      if (stalled) gamma = Math.max(gamma - 6 * h, -35); // it mushes down

      /* ---- roll ---- */
      const rollAuth = clamp(qRatio, 0.3, 1.6) * (stalled ? 0.4 : 1);
      let rollRate = rollIn * ROLL_RATE_MAX * rollAuth;
      rollRate -= bank * ROLL_STABILITY * (1 - 0.6 * Math.abs(rollIn));
      if (stalled) {
        // Asymmetric wing drop; deterministic but unpredictable to the pilot.
        rng = lcgNext(rng);
        rollRate += (lcgUnit(rng) - 0.5) * 26;
      }
      if (turbulence > 0) {
        rng = lcgNext(rng);
        rollRate += (lcgUnit(rng) - 0.5) * 22 * turbulence;
      }
      bank = clamp(bank + rollRate * h, -BANK_MAX, BANK_MAX);

      /* ---- yaw and sideslip ----
       * Bank turns the aeroplane; rudder yaws the nose. Cross-controlling
       * (bank into wind + opposite rudder) cancels the turn and leaves a
       * steady sideslip, which is exactly the crosswind landing technique:
       * the track (heading + beta) drifts toward the low wing. */
      const rudderAuth = clamp(qRatio, 0.3, 1.8) * (stalled ? 0.6 : 1);
      const turnRate = ((G * Math.tan(bankRad)) / vForPath) * RAD * (1 - 0.02 * absBeta);
      const headingRate = turnRate + rudderIn * RUDDER_YAW_RATE * rudderAuth;
      heading = wrap360(heading + headingRate * h);

      const betaTarget = -rudderIn * RUDDER_BETA_MAX * clamp(rudderAuth, 0.3, 1.2);
      beta += (betaTarget - beta) * lagAlpha(h, BETA_TAU);

      /* ---- attitude ---- */
      pitch = clamp(gamma + alpha, -25, 22);

      /* ---- kinematics in the runway frame ---- */
      const relTrackRad = (wrap180(heading - runwayHeading) + beta) * DEG;
      const horiz = tasFpsNew * Math.cos(gamma * DEG);
      const vxAir = horiz * Math.cos(relTrackRad);
      const vyAir = horiz * Math.sin(relTrackRad);
      const vx = vxAir + windX;
      const vy = vyAir + windY + gustV;
      vsFps = tasFpsNew * Math.sin(gamma * DEG) + gustW;

      x += vx * h;
      y += vy * h;
      alt += vsFps * h;

      groundSpeedKt = Math.sqrt(vx * vx + vy * vy) * FPS_TO_KT;
      groundTrack = wrap360(runwayHeading + Math.atan2(vy, vx) * RAD);

      /* ---------------- ground contact ---------------- */
      if (alt <= 0) {
        const impactVS = vsFps * FPM_PER_FPS;
        const impactKias = ktas * sqrtSigma;

        if (!touchedDown) {
          touchedDown = true;
          touchdownVS = impactVS;
          touchdownPoint = x;
          touchdownSpeed = impactKias;
          touchdownOffset = y;
          touchdownPitch = pitch;
          touchdownBank = bank;
        }

        // Crash screens, in order of severity.
        if (impactVS <= VS_HARD) {
          crashed = true;
          crashReason = 'Excessive descent rate at touchdown — gear collapse.';
        } else if (Math.abs(bank) > 15) {
          crashed = true;
          crashReason = 'Wingtip strike — too much bank at touchdown.';
        } else if (pitch < 0 && impactVS < -350) {
          crashed = true;
          crashReason = 'Nosewheel-first arrival — propeller strike.';
        } else if (pitch > 16) {
          crashed = true;
          crashReason = 'Over-rotated — tail strike.';
        } else if (x < -20) {
          crashed = true;
          crashReason = 'Landed short of the threshold.';
        } else if (x > RUNWAY_LENGTH) {
          crashed = true;
          crashReason = 'Touched down beyond the departure end.';
        }

        if (crashed) {
          alt = 0;
          gamma = 0;
          vsFps = 0;
          onGround = true;
          bank = clamp(bank, -20, 20);
        } else if (impactVS < VS_BOUNCE_THRESHOLD && impactKias > 45) {
          // Firm arrival with energy left: it skips.
          bounced = true;
          bounceCount++;
          alt = 0.6;
          vsFps = -vsFps * BOUNCE_RESTITUTION;
          gamma = (Math.asin(clamp(vsFps / Math.max(tasFpsNew, 20), -1, 1)) * RAD);
          alpha = Math.max(alpha - 1.5, alphaTrim - 2);
          if (bounceCount >= 3) {
            crashed = true;
            crashReason = 'Progressive bouncing — go around next time.';
            onGround = true;
            alt = 0;
            gamma = 0;
            vsFps = 0;
          }
        } else {
          onGround = true;
          alt = 0;
          gamma = 0;
          vsFps = 0;
          beta = 0;
        }
      }
    } else {
      /* ================= ON THE GROUND ================= */
      alt = 0;
      gamma = 0;
      vsFps = 0;

      // Nose relaxes toward level unless the pilot holds it off (aerodynamic
      // braking). Elevator authority fades with airspeed.
      const holdOff = pitchIn * PITCH_AUTHORITY_DEG * clamp(qRatio, 0, 1);
      const pitchTargetGround = clamp(holdOff, -1, 12);
      const pitchRate = pitchTargetGround > pitch ? 8 : -8;
      if (Math.abs(pitchTargetGround - pitch) < Math.abs(pitchRate * h)) pitch = pitchTargetGround;
      else pitch += pitchRate * h;
      pitch = clamp(pitch, -1, 12);
      alpha = pitch;

      // Wings level themselves on the gear.
      bank += (0 - bank) * lagAlpha(h, 0.5);

      // Deceleration: aerodynamic drag + wheel friction on the residual weight.
      const normalLoad = Math.max(WEIGHT - liftLb, 0);
      const mu = ROLLING_FRICTION + brakeIn * BRAKING_FRICTION;
      const decel = (dragLb + mu * normalLoad - thrustLb) / MASS;
      let tasFpsNew = Math.max(0, tasFps - decel * h);
      ktas = tasFpsNew * FPS_TO_KT;

      // Nosewheel steering, plus weathervaning into the crosswind.
      const gsKt = tasFpsNew * FPS_TO_KT;
      const steerAuth = clamp(gsKt / 40, 0, 1.4);
      let yawRate = rudderIn * NOSEWHEEL_AUTHORITY * steerAuth;
      yawRate += -crosswindKt * 0.06 * clamp(gsKt / 40, 0, 1);
      heading = wrap360(heading + yawRate * h);
      beta = 0;

      const relRad = wrap180(heading - runwayHeading) * DEG;
      const vx = tasFpsNew * Math.cos(relRad) + windX * 0.15;
      const vy = tasFpsNew * Math.sin(relRad) + windY * 0.15;
      x += vx * h;
      y += vy * h;
      groundSpeedKt = Math.sqrt(vx * vx + vy * vy) * FPS_TO_KT;
      groundTrack = gsKt > 1 ? wrap360(runwayHeading + Math.atan2(vy, vx) * RAD) : heading;

      // Departed the paved surface, or ran off the end.
      if (Math.abs(y) > RUNWAY_WIDTH / 2 + 10 && !crashed) {
        crashed = true;
        crashReason = 'Departed the runway surface.';
      } else if (x > RUNWAY_LENGTH && gsKt > 25 && !crashed) {
        crashed = true;
        crashReason = 'Runway overrun.';
      }

      if (kias < TAXI_COMPLETE_SPEED && !crashed) landingComplete = true;

      stalled = false;
      stallWarning = false;
      inGroundEffect = true;
    }
  }

  kias = ktas * Math.sqrt(Math.max(densityRatio, 0.2));

  /* ---------------- guidance readouts ---------------- */
  const distanceToThreshold = -x; // + when short of the threshold
  const glideDistance = AIM_POINT - x; // ft to the aiming point
  const idealAlt = glideDistance > 0 ? glideDistance * Math.tan(GLIDESLOPE_DEG * DEG) : 0;
  const glideslopeErrorFt = alt - idealAlt;
  const glideslopeErrorDeg =
    glideDistance > 50 ? Math.atan2(alt, glideDistance) * RAD - GLIDESLOPE_DEG : 0;

  /* ---------------- assemble the new state ---------------- */
  const next: PhysicsState = {
    time,
    frame: s.frame + 1,
    phase: s.phase,
    phaseTime: s.phaseTime + frameDt,
    rngState: rng,

    x,
    y,
    altitudeAgl: alt,
    fieldElevation: s.fieldElevation,
    altitudeMsl: s.fieldElevation + alt,

    airspeedKias: kias,
    airspeedKtas: ktas,
    groundSpeedKt,
    verticalSpeedFpm: vsFps * FPM_PER_FPS,
    groundTrackDeg: groundTrack,

    pitchDeg: pitch,
    bankDeg: bank,
    headingDeg: heading,
    alphaDeg: alpha,
    betaDeg: beta,
    flightPathDeg: gamma,

    flapsDeg: flaps,
    flapTargetDeg: flapRequest,
    rpm,
    throttle: throttleIn,
    carbHeat,
    powerFraction,
    thrustLb,
    liftLb,
    dragLb,
    loadFactor,

    stalled,
    stallWarning,
    stallSpeedKias,
    overspeed,
    onGround,
    inGroundEffect,

    runwayHeading,
    distanceToThreshold,
    glideslopeErrorFt,
    glideslopeErrorDeg,
    centerlineOffsetFt: y,
    crosswindComponentKt: crosswindKt,
    headwindComponentKt: headwindKt,

    densityAltitude,
    densityRatio,
    gustLongitudinal: gustU,
    gustVertical: gustW,
    gustLateral: gustV,

    touchedDown,
    touchdownVS,
    touchdownPoint,
    touchdownSpeedKias: touchdownSpeed,
    touchdownCenterlineOffset: touchdownOffset,
    touchdownPitchDeg: touchdownPitch,
    touchdownBankDeg: touchdownBank,
    bounceCount,
    bounced,
    crashed,
    crashReason,
    landingComplete,
  };

  // Phase is evaluated from the freshly integrated state; reset the phase
  // timer on a transition.
  const newPhase = evaluatePhaseTransition(next as unknown as FlightState);
  if (newPhase !== next.phase) {
    next.phase = newPhase;
    next.phaseTime = 0;
  }

  return next as unknown as FlightState;
}

/* ==========================================================================
 * 11. PUBLIC: evaluatePhaseTransition
 * ========================================================================== */

/**
 * Pure phase classifier. Boundaries:
 *   downwind -> abeam     : abeam the aiming point (x <= 500) at pattern-ish alt
 *   abeam    -> base      : threshold 45 deg behind the wing (x <= -|y|)
 *   base     -> final     : within 20 deg of runway heading, inside 300 ft of
 *                           centerline, approaching from x < 0
 *   final    -> roundout  : 15 ft AGL
 *   roundout -> flare     : 6 ft AGL
 *   flare    -> touchdown : wheels on
 *   touchdown-> rollout   : on the ground and decelerating
 *   rollout  -> complete  : below 20 KIAS
 *   any      -> go-around : full power, climbing away below 400 ft
 *   any      -> crashed   : crash flag
 */
export function evaluatePhaseTransition(state: FlightState): FlightPhase {
  const s = state as unknown as PhysicsState;

  if (s.crashed) return PHASE.crashed;
  if (s.landingComplete) return PHASE.complete;

  const phase = s.phase as unknown as string;
  const relHeading = wrap180(s.headingDeg - s.runwayHeading);
  const absRel = relHeading < 0 ? -relHeading : relHeading;
  const absY = s.y < 0 ? -s.y : s.y;

  /* ---- on the ground ---- */
  if (s.onGround) {
    if (s.airspeedKias < TAXI_COMPLETE_SPEED) return PHASE.complete;
    if (phase === 'touchdown' && s.phaseTime > 1) return PHASE.rollout;
    if (phase === 'rollout') return PHASE.rollout;
    return PHASE.touchdown;
  }

  /* ---- go-around: firewalled, climbing, low ---- */
  const goingAround =
    s.rpm > 2400 &&
    s.verticalSpeedFpm > 150 &&
    (phase === 'final' || phase === 'roundout' || phase === 'flare' || phase === 'go-around');
  if (goingAround && s.altitudeAgl < 900) return PHASE.goAround;

  if (phase === 'go-around') {
    // Rejoin the downwind once cleaned up, at altitude, and past the field.
    if (s.altitudeAgl >= PATTERN_ALTITUDE - 150 && s.x > 1000 && absRel > 150) {
      return PHASE.downwind;
    }
    return PHASE.goAround;
  }

  /* ---- airborne, in the pattern ---- */
  if (s.altitudeAgl <= 6) return PHASE.flare;
  if (s.altitudeAgl <= 15) return PHASE.roundout;

  // Established on final: aligned, near the centerline, still short of the
  // threshold (or over the first part of the runway).
  const alignedFinal = absRel < 20 && absY < 300 && s.x < 500;
  if (alignedFinal) return PHASE.final;

  // Base leg: the threshold has fallen 45 degrees or more behind the wing.
  if (phase === 'downwind' || phase === 'abeam' || phase === 'base') {
    if (s.x <= -absY) return PHASE.base;
    if (phase === 'base') return PHASE.base;
    // Abeam: still on the downwind heading, past the aiming point.
    if (absRel > 150 && s.x <= AIM_POINT + 200) return PHASE.abeam;
    return PHASE.downwind;
  }

  if (phase === 'final' || phase === 'roundout' || phase === 'flare') return PHASE.final;
  return s.phase;
}

/* ==========================================================================
 * 12. PUBLIC: detectLanding
 * ========================================================================== */

/**
 * Landing report. Call when altitude reaches 0 (or any time after — the
 * touchdown record is latched into the state at first contact).
 *   touchdownVS       fpm, negative down
 *   touchdownPoint    ft past the threshold
 *   centerlineOffset  ft, + right of centerline
 */
export function detectLanding(state: FlightState): {
  landed: boolean;
  touchdownVS: number;
  touchdownPoint: number;
  centerlineOffset: number;
  bounced: boolean;
  crashed: boolean;
} {
  const s = state as unknown as PhysicsState;

  if (s.touchedDown) {
    return {
      landed: !s.crashed,
      touchdownVS: s.touchdownVS,
      touchdownPoint: s.touchdownPoint,
      centerlineOffset: s.touchdownCenterlineOffset,
      bounced: s.bounceCount > 0,
      crashed: s.crashed,
    };
  }

  // Not latched yet — evaluate the current instant.
  const contact = s.altitudeAgl <= 0;
  const vs = s.verticalSpeedFpm;
  return {
    landed: contact && !s.crashed,
    touchdownVS: contact ? vs : 0,
    touchdownPoint: contact ? s.x : 0,
    centerlineOffset: contact ? s.y : s.y,
    bounced: s.bounceCount > 0,
    crashed: s.crashed || (contact && vs <= VS_HARD),
  };
}

export type TouchdownGrade = 'greaser' | 'firm' | 'hard' | 'crash';

/** -100..-200 greaser, -200..-400 firm, -400..-600 hard, beyond -600 crash. */
export function gradeTouchdown(touchdownVS: number): TouchdownGrade {
  if (touchdownVS <= VS_HARD) return 'crash';
  if (touchdownVS <= VS_FIRM) return 'hard';
  if (touchdownVS <= VS_GREASER) return 'firm';
  return 'greaser';
}

import type { LandingResult, ScoreBreakdown } from './types';

type Telemetry = Record<string, unknown>;

const clamp = (value: number, min = 0, max = 20): number =>
  Math.min(max, Math.max(min, value));
const points = (value: number): number => Math.round(clamp(value));

function numberFrom(source: Telemetry, names: string[], fallback = 0): number {
  for (const name of names) {
    const value = source[name];
    if (typeof value === 'number' && Number.isFinite(value)) return value;
  }
  return fallback;
}

function numbersFrom(source: Telemetry, names: string[]): number[] {
  for (const name of names) {
    const value = source[name];
    if (Array.isArray(value)) {
      const values = value.filter(
        (item): item is number => typeof item === 'number' && Number.isFinite(item),
      );
      if (values.length) return values;
    }
  }
  return [];
}

function countOutside(values: number[], minimum: number, maximum: number): number {
  return values.filter((value) => value < minimum || value > maximum).length;
}

function approachScore(result: Telemetry): number {
  let score = 20;
  const speeds = numbersFrom(result, ['approachSpeeds', 'finalApproachSpeeds', 'speedHistory']);
  const sampledApproachSpeed = numberFrom(
    result,
    ['approachSpeed', 'finalApproachSpeed', 'airspeedOnFinal'],
    65,
  );
  const speedExcursions = numberFrom(
    result,
    ['speedExcursions'],
    speeds.length
      ? countOutside(speeds, 60, 70)
      : sampledApproachSpeed < 60 || sampledApproachSpeed > 70
        ? 1
        : 0,
  );
  score -= Math.min(8, speedExcursions * 2);
  if (!speeds.length) score -= Math.min(4, Math.max(0, Math.abs(sampledApproachSpeed - 65) - 5) * 0.5);

  const glide = numbersFrom(result, [
    'glideslopeDeviations',
    'papiDeviations',
    'glideslopeHistory',
  ]);
  const averageGlideError = glide.length
    ? glide.reduce((sum, value) => sum + Math.abs(value), 0) / glide.length
    : Math.abs(numberFrom(result, ['glideslopeDeviation', 'papiDeviation'], 0));
  score -= Math.min(6, averageGlideError * 4);
  score -= Math.min(4, numberFrom(result, ['glideslopeChasing', 'glideslopeCorrections'], 0));

  const centerline = numbersFrom(result, [
    'approachCenterlineOffsets',
    'centerlineHistory',
    'finalCenterlineOffsets',
  ]);
  const averageCenterlineError = centerline.length
    ? centerline.reduce((sum, value) => sum + Math.abs(value), 0) / centerline.length
    : Math.abs(numberFrom(result, ['approachCenterlineOffset'], 0));
  score -= Math.min(5, averageCenterlineError / 6);
  score -= Math.min(5, numberFrom(result, ['sTurns', 'sTurnCount'], 0) * 2.5);

  return points(score);
}

function flareScore(result: Telemetry): number {
  const altitude = numberFrom(result, ['flareStartAltitude', 'flareAltitude'], 0);
  if (altitude >= 10 && altitude <= 15) return 20;
  if (altitude > 15) return points(20 - (altitude - 15) * 1.25);
  return points(20 - (10 - altitude) * 2);
}

function touchdownScore(result: Telemetry): number {
  const verticalSpeed = Math.abs(
    numberFrom(result, ['touchdownVerticalSpeed', 'verticalSpeedAtTouchdown', 'touchdownVS'], 0),
  );
  let score: number;

  if (verticalSpeed >= 100 && verticalSpeed <= 200) score = 20;
  else if (verticalSpeed < 100) score = 18 + (verticalSpeed / 100) * 2;
  else if (verticalSpeed <= 400) score = 16 - ((verticalSpeed - 200) / 200) * 4;
  else if (verticalSpeed <= 600) score = 10 - ((verticalSpeed - 400) / 200) * 4;
  else score = 4 - ((verticalSpeed - 600) / 200) * 4;

  const airspeed = numberFrom(
    result,
    ['touchdownAirspeed', 'airspeedAtTouchdown', 'touchdownSpeed'],
    50,
  );
  score -= Math.min(4, Math.abs(airspeed - 50) * 0.4);
  return points(score);
}

function zoneScore(result: Telemetry): number {
  const distance = Math.max(
    0,
    numberFrom(result, ['touchdownDistance', 'touchdownDistanceFromThreshold', 'touchdownPoint'], 0),
  );
  const runwayLength = numberFrom(result, ['runwayLength', 'runwayLengthFeet'], 9000);
  const idealLimit = Math.min(3000, runwayLength / 3);
  if (distance <= idealLimit) return 20;
  if (distance >= 5000) return 0;
  return points(20 * (1 - (distance - idealLimit) / (5000 - idealLimit)));
}

function directionalScore(result: Telemetry): number {
  const offset = Math.abs(
    numberFrom(result, ['centerlineOffset', 'touchdownCenterlineOffset'], 0),
  );
  let score = offset <= 10 ? 20 : 20 - (offset - 10);

  const crosswind = Math.abs(numberFrom(result, ['crosswindComponent', 'crosswind'], 0));
  const decrabError = Math.abs(
    numberFrom(result, ['decrabError', 'touchdownCrabAngle', 'headingErrorAtTouchdown'], 0),
  );
  if (crosswind >= 3) score -= Math.min(8, decrabError * 1.25);
  return points(score);
}

export function qualityFromTotal(
  total: number,
): 'greaser' | 'good' | 'firm' | 'hard' | 'bounce' | 'crash' {
  const value = Math.min(100, Math.max(0, total));
  if (value >= 90) return 'greaser';
  if (value >= 75) return 'good';
  if (value >= 60) return 'firm';
  if (value >= 40) return 'hard';
  if (value >= 20) return 'bounce';
  return 'crash';
}

export function scoreLanding(result: LandingResult): ScoreBreakdown {
  const telemetry = result as unknown as Telemetry;
  const approachStability = approachScore(telemetry);
  const flareTiming = flareScore(telemetry);
  const touchdownQuality = touchdownScore(telemetry);
  const touchdownZone = zoneScore(telemetry);
  const centerlineControl = directionalScore(telemetry);
  const total =
    approachStability + flareTiming + touchdownQuality + touchdownZone + centerlineControl;

  return {
    approachStability,
    flareTiming,
    touchdownQuality,
    touchdownZone,
    centerlineControl,
    total,
  } as ScoreBreakdown;
}

function hash(text: string): number {
  let value = 2166136261;
  for (let i = 0; i < text.length; i += 1) {
    value ^= text.charCodeAt(i);
    value = Math.imul(value, 16777619);
  }
  return value >>> 0;
}

function seededRange(seed: number, minimum: number, maximum: number): number {
  return minimum + (seed % (maximum - minimum + 1));
}

export function computeDifficulty(lastScores: number[]): DifficultyLevel {
  const recent = lastScores
    .slice(-5)
    .filter(Number.isFinite)
    .map((score) => clamp(score, 0, 100));
  if (recent.length === 0) return 0 as DifficultyLevel;

  const average = recent.reduce((sum, score) => sum + score, 0) / recent.length;
  if (average < 40) return 0 as DifficultyLevel;
  if (average < 60) return 1 as DifficultyLevel;
  if (average < 75) return 2 as DifficultyLevel;
  if (average < 90) return 3 as DifficultyLevel;
  return 4 as DifficultyLevel;
}

type QueuedCallout = {

type CalloutShape = {

  text: string;

function makeCallout(id: string, text: string, priority: number): VoiceCallout {
  return { id, text, priority } as unknown as VoiceCallout;
}

function numberFrom(source: StateLike, ...keys: string[]): number | undefined {
  for (const key of keys) {
    const value = source[key];
    if (typeof value === "number" && Number.isFinite(value)) return value;
  }
  return undefined;
}

function booleanFrom(source: StateLike, ...keys: string[]): boolean {
  return keys.some((key) => source[key] === true);

  return String(phase).toLowerCase().replace(/[\s_-]+/g, "");
}

function lastCalloutIdentity(lastCallout: VoiceCallout | null): string {
  if (!lastCallout) return "";
  const value = lastCallout as unknown as Partial<CalloutShape>;
  return `${value.id ?? ""} ${value.text ?? ""}`.toLowerCase();
}

/**
 * Browser speech-synthesis queue for the FlightCourse Academy CFI, "Coach".
 * Call speak() from the game loop; duplicate text is suppressed until
 * resetCallouts() is called for the next landing.
 */
export class VoiceCoach {
  private enabled = false;
  private volume = 1;
  private voiceURI: string | null = null;
  private queue: QueuedCallout[] = [];
  private fired = new Set<string>();
  private speaking = false;
  private currentPriority = 0;
  private lastFinishedAt = -Infinity;
  private sequence = 0;
  private timer: ReturnType<typeof setTimeout> | null = null;
  private generation = 0;

  enable(): void {
    this.setEnabled(true);
  }

  disable(): void {
    this.setEnabled(false);
  }

  setVoice(voiceURI: string): void {
    this.voiceURI = voiceURI || null;
  }

  setVolume(value: number): void {
    this.volume = Math.max(0, Math.min(1, value));
  }

  setEnabled(enabled: boolean): void {
    this.enabled = enabled;
    if (!enabled) {
      this.generation += 1;
      this.queue.length = 0;
      this.speaking = false;
      this.currentPriority = 0;
      if (this.timer !== null) clearTimeout(this.timer);
      this.timer = null;
      if (typeof window !== "undefined" && "speechSynthesis" in window) {
        window.speechSynthesis.cancel();
      }
      return;
    }

    if (typeof window !== "undefined" && "speechSynthesis" in window) {
      window.speechSynthesis.resume();
      this.pump();
    }
  }

  speak(text: string, priority = 3): void {
    const cleanText = text.trim();
    if (!this.enabled || !cleanText || typeof window === "undefined") return;
    if (!("speechSynthesis" in window) || !("SpeechSynthesisUtterance" in window)) return;

    const key = cleanText.toLocaleLowerCase();
    if (this.fired.has(key) || this.queue.some((item) => item.text.toLocaleLowerCase() === key)) {
      return;
    }

    const safePriority = Math.max(1, Math.min(5, Math.round(priority)));
    this.fired.add(key);

    if (safePriority === 5 && this.speaking && this.currentPriority < 5) {
      this.generation += 1;
      window.speechSynthesis.cancel();
      this.speaking = false;
      this.currentPriority = 0;
      this.queue.unshift({ text: cleanText, priority: safePriority, order: this.sequence++ });
      this.pump(true);
      return;
    }

    this.queue.push({ text: cleanText, priority: safePriority, order: this.sequence++ });
    this.queue.sort((a, b) => b.priority - a.priority || a.order - b.order);
    this.pump();
  }

  resetCallouts(): void {
    this.fired.clear();
    this.queue.length = 0;
    this.generation += 1;
    this.speaking = false;
    this.currentPriority = 0;
    this.lastFinishedAt = -Infinity;
    if (this.timer !== null) clearTimeout(this.timer);
    this.timer = null;
    if (typeof window !== "undefined" && "speechSynthesis" in window) {
      window.speechSynthesis.cancel();
    }
  }

  private pump(ignoreGap = false): void {
    if (!this.enabled || this.speaking || this.queue.length === 0) return;
    if (typeof window === "undefined" || !("speechSynthesis" in window)) return;

    if (this.timer !== null) {
      clearTimeout(this.timer);
      this.timer = null;
    }

    const wait = ignoreGap ? 0 : Math.max(0, MIN_CALLOUT_GAP_MS - (Date.now() - this.lastFinishedAt));
    if (wait > 0) {
      this.timer = setTimeout(() => {
        this.timer = null;
        this.pump();
      }, wait);
      return;
    }

    const next = this.queue.shift();
    if (!next) return;

    const utterance = new SpeechSynthesisUtterance(next.text);
    utterance.volume = this.volume;
    utterance.rate = 0.96;
    utterance.pitch = 0.93;

    if (this.voiceURI) {
      const voice = window.speechSynthesis
        .getVoices()
        .find((candidate) => candidate.voiceURI === this.voiceURI);
      if (voice) utterance.voice = voice;
    }

    const token = this.generation;
    this.speaking = true;
    this.currentPriority = next.priority;

    const finish = (): void => {
      if (token !== this.generation) return;
      this.speaking = false;
      this.currentPriority = 0;
      this.lastFinishedAt = Date.now();
      this.pump();
    };

    utterance.onend = finish;
    utterance.onerror = finish;
    window.speechSynthesis.speak(utterance);
  }
}

  // fallback — which in this engine is the along-runway distance in feet,

  // constantly and nonsensically.
  const altitude = numberFrom(s, "radarAltitude", "altitudeAgl", "agl", "altitude") ?? Infinity;
  const airspeed = numberFrom(s, "airspeedKias", "airspeed", "indicatedAirspeed", "ias") ?? 65;

  const floating = booleanFrom(s, "isFloating", "floating") || (altitude < 12 && altitude > 1.5 && Math.abs(verticalSpeed) < 80);
  const landed = booleanFrom(s, "landed", "onGround", "touchdown") || p.includes("landed") || p.includes("rollout");

export class AudioEngine {

  private master: GainNode | null = null;
  private muted = false;
  private stall: StallNodes | null = null;

  /**
   * Lazily creates and resumes the AudioContext. Call from a click, tap, or
   * keyboard handler so browser autoplay policies allow sound.
   */
  init(): AudioContext | null {
    if (typeof window === "undefined") return null;

    if (!this.context) {
      const AudioContextClass =
        window.AudioContext ?? (window as WebkitAudioWindow).webkitAudioContext;
      if (!AudioContextClass) return null;

      this.context = new AudioContextClass();
      this.master = this.context.createGain();
      this.master.gain.value = this.muted ? 0 : 1;
      this.master.connect(this.context.destination);
    }

    if (this.context.state === "suspended") {
      void this.context.resume();
    }

    return this.context;
  }

    if (!this.context || !this.master) return;

    const now = this.context.currentTime;
    this.master.gain.cancelScheduledValues(now);
    this.master.gain.setTargetAtTime(muted ? 0 : 1, now, 0.01);
  }

    const gain = audio.createGain();

    filter.frequency.setValueAtTime(1_800 + amount * 500, now);
    filter.Q.setValueAtTime(2.2 + amount * 2.5, now);

    gain.gain.setValueAtTime(0.0001, now);
    gain.gain.exponentialRampToValueAtTime(0.08 + amount * 0.32, now + 0.008);
    gain.gain.exponentialRampToValueAtTime(0.0001, now + duration);

    noise.connect(filter).connect(gain).connect(this.master);
    noise.start(now);
    noise.stop(now + duration + 0.02);
  }

    nodes.gain.gain.cancelScheduledValues(now);
    nodes.gain.gain.setTargetAtTime(0, now, 0.015);

    const stopAt = now + 0.08;
    nodes.horn.stop(stopAt);
    nodes.pulse.stop(stopAt);
    nodes.horn.onended = () => {
      nodes.horn.disconnect();
      nodes.pulse.disconnect();
      nodes.pulseDepth.disconnect();
      nodes.gain.disconnect();
    };
  }

    noiseGain.gain.setValueAtTime(0.85, now);
    noiseGain.gain.exponentialRampToValueAtTime(0.0001, now + 0.5);

    noise.stop(now + duration);

    const oscillator = audio.createOscillator();
    const gain = audio.createGain();

    gain.gain.setValueAtTime(0.16, now);
    gain.gain.exponentialRampToValueAtTime(0.0001, now + 0.02);

    oscillator.start(now);
    oscillator.stop(now + 0.022);
  }

  private createNoiseBuffer(audio: AudioContext, duration: number): AudioBuffer {
    const frameCount = Math.max(1, Math.ceil(audio.sampleRate * duration));
    const buffer = audio.createBuffer(1, frameCount, audio.sampleRate);
    const samples = buffer.getChannelData(0);
    for (let i = 0; i < frameCount; i += 1) {
      samples[i] = Math.random() * 2 - 1;
    }
    return buffer;
  }

  private clamp01(value: number): number {
    return Math.max(0, Math.min(1, Number.isFinite(value) ? value : 0));
  }

const random = (min: number, max: number) => min + Math.random() * (max - min);

        this.explosion(touchdownPoint, 34);
        this.setFlash(0.38, 0.9, "235, 38, 30", "full");
        this.setZoom(0.35, -0.07);
        break;
    }

  /** Advances all effects and returns [shakeX, shakeY, zoom, flashAlpha]. */
  update(dt: number): number[] {
    const step = Math.max(0, Math.min(dt, 0.05));

    if (this.shakeTime > 0) {
      this.shakeTime = Math.max(0, this.shakeTime - step);
      const envelope = this.shakeDuration > 0 ? this.shakeTime / this.shakeDuration : 0;
      const amplitude = this.shakeAmplitude * envelope * envelope;
      this.transform[0] = random(-amplitude, amplitude);
      this.transform[1] = random(-amplitude, amplitude);
    } else {
      this.transform[0] = 0;
      this.transform[1] = 0;
    }

    if (this.zoomTime > 0) {
      this.zoomTime = Math.max(0, this.zoomTime - step);
      const progress = 1 - this.zoomTime / Math.max(this.zoomDuration, 0.001);
      this.transform[2] = 1 + this.zoomAmount * Math.sin(progress * Math.PI);
    } else {
      this.transform[2] = 1;
    }

    if (this.flashTime > 0) {
      this.flashTime = Math.max(0, this.flashTime - step);
      const remaining = this.flashTime / Math.max(this.flashDuration, 0.001);
      this.transform[3] = this.flashStrength * remaining * remaining;
    } else {
      this.transform[3] = 0;
      this.flashMode = "none";
    }

    if (this.stallHold > 0) {
      this.stallHold = Math.max(0, this.stallHold - step);
      this.stallPhase += step * 9;
      this.stallAlpha = clamp01(0.08 + (0.5 + 0.5 * Math.sin(this.stallPhase * TAU)) * 0.28);
    } else {
      this.stallAlpha = Math.max(0, this.stallAlpha - step * 2.5);
    }

    for (const p of this.particles) {
      if (!p.active) continue;
      p.life -= step;
      if (p.life <= 0) { p.active = false; continue; }
      const damping = Math.pow(p.drag, step * 60);
      p.vx *= damping;
      p.vy = p.vy * damping + p.gravity * step;
      p.x += p.vx * step;
      p.y += p.vy * step;
      p.size = Math.max(0.1, p.size + p.grow * step);
    }
    return this.transform;
  }

const weakDimensionFor = (history: ScoreBreakdown[]): string | null => {
  if (history.length < 3) return null;

  const sums = new Map<string, { total: number; count: number }>();
  for (const score of history) {
    for (const [key, rawValue] of Object.entries(
      score as unknown as Record<string, unknown>,
    )) {
      if (
        key === "total" ||
        typeof rawValue !== "number" ||
        !Number.isFinite(rawValue)
      )
        continue;
      const current = sums.get(key) ?? { total: 0, count: 0 };
      current.total += rawValue;
      current.count += 1;
      sums.set(key, current);
    }
  }

  let weakest: string | null = null;
  let lowestAverage = Infinity;
  for (const [key, value] of sums) {
    if (value.count < 3) continue;
    const average = value.total / value.count;
    if (average < lowestAverage) {
      weakest = key;
      lowestAverage = average;
    }
  }
  return weakest;
};

export function drawScene(
  ctx: CanvasRenderingContext2D,
  state: FlightState,
  weather: WeatherConditions,
  w: number,
  h: number,
): void {
  if (!(w > 0 && h > 0)) return;

  const source = state as unknown as AnyRecord;
  const position = record(source.position);
  const attitude = record(source.attitude);
  // PATCHED: added the exact field names flight-physics.ts's FlightState
  // actually uses (altitudeAgl, pitchDeg, bankDeg, centerlineOffsetFt,
  // glideslopeErrorDeg) as first-choice aliases — the originals here didn't
  // match flight-physics.ts's casing/naming and would have silently fallen
  // back to defaults every frame.
  const altitude = Math.max(0, firstNumber(source, position, "altitudeAgl", "altitudeAGL", "altitude", 300));
  const pitch = firstNumber(source, attitude, "pitchDeg", "pitch", "pitchDegrees", 0);
  const bank = firstNumber(source, attitude, "bankDeg", "bank", "bankDegrees", 0);
  const lateral = firstNumber(source, position, "centerlineOffsetFt", "lateralOffset", "centerlineOffset", 0);
  const distance = Math.max(1, firstNumber(source, position, "distanceToThreshold", "distanceFromThreshold", "runwayDistance", 2500));
  let glideDeviation = firstNumber(source, null, "glideslopeErrorDeg", "glideslopeDeviation", "glideSlopeDeviation", Number.NaN);
  if (!Number.isFinite(glideDeviation)) {
    glideDeviation = Math.atan2(altitude, distance) / DEG - 3;
  }

  const cache = cacheFor(ctx, weather, w, h);
  const altitudeFactor = clamp(altitude / 1400, 0, 1);
  const distanceFactor = clamp(distance / 6500, 0, 1);
  const pitchShift = clamp(pitch, -15, 22) * h * .0062;
  const horizonY = clamp(h * .39 + pitchShift, h * .15, h * .68);

  /* At altitude the runway is smaller and its visual center sits lower. */
  const runwaySpan = h * (.68 - altitudeFactor * .28 - distanceFactor * .05);
  const runwayCenterY = horizonY + h * (.36 + altitudeFactor * .06);
  const runwayTop = Math.max(horizonY + 2, runwayCenterY - runwaySpan * .5 - pitchShift * .28);
  const runwayBottom = clamp(runwayCenterY + runwaySpan * .5 - pitchShift * .72, runwayTop + h * .16, h * 1.16);

  const offset = clamp(lateral, -300, 300);
  const topCenter = w * .5 - offset * w * .0007;
  const bottomCenter = w * .5 - offset * w * .0032;
  const topHalf = w * (.0065 + (1 - distanceFactor) * .005);
  const bottomHalf = w * (.51 - altitudeFactor * .22 - distanceFactor * .05);
  const bankRadians = -clamp(bank, -50, 50) * DEG;

  ctx.clearRect(0, 0, w, h);
  ctx.fillStyle = cache.sky ?? cache.palette.skyTop;
  ctx.fillRect(0, 0, w, h);
  if (cache.paletteId === 2) drawStars(ctx, w, h);

  ctx.save();
  ctx.translate(w * .5, horizonY);
  ctx.rotate(bankRadians);
  ctx.translate(-w * .5, -horizonY);

  drawTerrain(ctx, w, h, horizonY, cache);

  ctx.fillStyle = cache.runway ?? cache.palette.runwayTop;
  ctx.beginPath();
  ctx.moveTo(topCenter - topHalf, runwayTop);
  ctx.lineTo(topCenter + topHalf, runwayTop);
  ctx.lineTo(bottomCenter + bottomHalf, runwayBottom);
  ctx.lineTo(bottomCenter - bottomHalf, runwayBottom);
  ctx.closePath();
  ctx.fill();

  ctx.strokeStyle = cache.palette.marking;
  ctx.lineWidth = Math.max(1.2, h * .0028);
  ctx.setLineDash(NO_DASH);
  ctx.beginPath();
  ctx.moveTo(topCenter - topHalf, runwayTop);
  ctx.lineTo(bottomCenter - bottomHalf, runwayBottom);
  ctx.moveTo(topCenter + topHalf, runwayTop);
  ctx.lineTo(bottomCenter + bottomHalf, runwayBottom);
  ctx.stroke();

  ctx.fillStyle = cache.palette.marking;
  for (let i = 0; i < 10; i += 1) {

  }
  return fallback;
}

function RadarChart({ dimensions, weakDimension }: { dimensions: Dimension[]; weakDimension: string }) {
  const center = 120;
  const radius = 76;
  const labelRadius = 104;
  const point = (index: number, distance: number) => {
    const angle = -Math.PI / 2 + (index * Math.PI * 2) / dimensions.length;
    return [center + Math.cos(angle) * distance, center + Math.sin(angle) * distance] as const;
  };
  const polygon = (scale: number) =>
    dimensions.map((_, index) => point(index, radius * scale).join(",")).join(" ");
  const scorePolygon = dimensions
    .map((dimension, index) => point(index, radius * (clamp(dimension.value) / 100)).join(","))
    .join(" ");
  const normalizedWeak = weakDimension.toLowerCase().replace(/[\s_-]/g, "");

  return (
    <div className="glass" style={{ padding: "18px", display: "grid", placeItems: "center" }}>
      <div className="label-instrument" style={{ justifySelf: "start", width: "100%" }}>PERFORMANCE PROFILE</div>
      <svg viewBox="0 0 240 240" role="img" aria-label="Five-dimension landing score chart" style={{ width: "min(100%, 310px)", overflow: "visible" }}>
        {[0.25, 0.5, 0.75, 1].map((scale) => (
          <polygon key={scale} points={polygon(scale)} fill="none" stroke="var(--border)" strokeWidth="1" opacity={scale === 1 ? 0.9 : 0.45} />
        ))}
        {dimensions.map((dimension, index) => {
          const [x, y] = point(index, radius);
          const [lx, ly] = point(index, labelRadius);
          const isWeak = dimension.key.replace(/[\s_-]/g, "") === normalizedWeak;
          return (
            <g key={dimension.key}>
              <line x1={center} y1={center} x2={x} y2={y} stroke={isWeak ? "var(--accent)" : "var(--border)"} strokeWidth={isWeak ? 2 : 1} />
              <circle cx={x} cy={y} r={isWeak ? 4 : 2} fill={isWeak ? "var(--accent)" : "var(--border)"} />
              <text x={lx} y={ly - 3} textAnchor="middle" dominantBaseline="middle" className="label-instrument" fill={isWeak ? "var(--accent)" : "var(--muted-foreground)"} fontSize="8">
                {dimension.label.toUpperCase()}
              </text>
              <text x={lx} y={ly + 9} textAnchor="middle" dominantBaseline="middle" className="nums" fill={isWeak ? "var(--accent)" : "currentColor"} fontSize="9">
                {Math.round(dimension.value)}
              </text>
            </g>
          );
        })}
        <polygon points={scorePolygon} fill="var(--primary)" fillOpacity="0.2" stroke="var(--primary)" strokeWidth="2" />
      </svg>
    </div>
  );
}

function MiniReplay({ frames }: { frames: ReplayPoint[] }) {
  const canvasRef = useRef<HTMLCanvasElement>(null);
  const [progress, setProgress] = useState(0);
  const dragging = useRef(false);

  useEffect(() => {
    const started = performance.now();
    let frameId = 0;
    const animate = (now: number) => {
      if (!dragging.current) setProgress(((now - started) % 5000) / 5000);
      frameId = requestAnimationFrame(animate);
    };
    frameId = requestAnimationFrame(animate);
    return () => cancelAnimationFrame(frameId);
  }, []);

  useEffect(() => {
    const canvas = canvasRef.current;
    if (!canvas || frames.length < 2) return;
    const rect = canvas.getBoundingClientRect();
    const dpr = Math.min(window.devicePixelRatio || 1, 2);
    canvas.width = Math.max(1, Math.round(rect.width * dpr));
    canvas.height = Math.max(1, Math.round(rect.height * dpr));
    const ctx = canvas.getContext("2d");
    if (!ctx) return;
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    const width = rect.width;
    const height = rect.height;
    const pad = 10;
    const minTime = frames[0].time;
    const maxTime = frames[frames.length - 1].time || minTime + 1;
    const altMax = Math.max(1, ...frames.map((frame) => frame.altitude));
    const speeds = frames.map((frame) => frame.speed);
    const speedMin = Math.min(...speeds);
    const speedMax = Math.max(speedMin + 1, ...speeds);
    const x = (time: number) => pad + ((time - minTime) / (maxTime - minTime)) * (width - pad * 2);
    const drawTrace = (color: string, value: (frame: ReplayPoint) => number, min: number, max: number) => {
      ctx.beginPath();
      frames.forEach((frame, index) => {
        const px = x(frame.time);
        const py = height - pad - ((value(frame) - min) / (max - min)) * (height - pad * 2);
        if (index === 0) ctx.moveTo(px, py); else ctx.lineTo(px, py);
      });
      ctx.strokeStyle = color;
      ctx.lineWidth = 1.5;
      ctx.stroke();
    };
    ctx.clearRect(0, 0, width, height);
    ctx.fillStyle = "color-mix(in srgb, var(--background) 72%, transparent)";
    ctx.fillRect(0, 0, width, height);
    ctx.strokeStyle = "var(--border)";
    ctx.strokeRect(0.5, 0.5, width - 1, height - 1);
    drawTrace("var(--primary)", (frame) => frame.altitude, 0, altMax);
    drawTrace("var(--accent)", (frame) => frame.speed, speedMin, speedMax);
    const cursorX = pad + progress * (width - pad * 2);
    ctx.strokeStyle = "rgba(255,255,255,.8)";
    ctx.beginPath();
    ctx.moveTo(cursorX, 4);
    ctx.lineTo(cursorX, height - 4);
    ctx.stroke();
  }, [frames, progress]);

  const scrub = useCallback((clientX: number) => {
    const canvas = canvasRef.current;
    if (!canvas) return;
    const rect = canvas.getBoundingClientRect();
    setProgress(clamp((clientX - rect.left) / rect.width, 0, 1));
  }, []);

  return (
    <div style={{ marginTop: "20px" }}>
      <div style={{ display: "flex", justifyContent: "space-between", marginBottom: "7px" }}>
        <span className="label-instrument">LAST 10 SECONDS</span>
        <span className="label-instrument"><span style={{ color: "var(--primary)" }}>ALT</span> / <span style={{ color: "var(--accent)" }}>KIAS</span></span>
      </div>
      <canvas
        ref={canvasRef}
        aria-label="Landing altitude and airspeed replay; drag to scrub"
        style={{ width: "100%", height: "64px", display: "block", cursor: "ew-resize", touchAction: "none" }}
        onPointerDown={(event) => { dragging.current = true; event.currentTarget.setPointerCapture(event.pointerId); scrub(event.clientX); }}
        onPointerMove={(event) => { if (dragging.current) scrub(event.clientX); }}
        onPointerUp={(event) => { dragging.current = false; event.currentTarget.releasePointerCapture(event.pointerId); }}
        onPointerCancel={() => { dragging.current = false; }}
      />
    </div>
  );
}

  dt = 1 / 60,
  env: GameEnv = createEnv(),
): FlightState {
  if (!Number.isFinite(dt) || dt <= 0) return { ...previous };
  const state = { ...previous };
  dt = Math.min(dt, 0.1); // prevents tab-resume physics explosions
  const targetThrottle = clamp(input.throttle ?? state.throttle, 0, 1);
  state.throttle = approach(state.throttle, targetThrottle, 1.2, dt);
  const targetFlap = [0, 10, 20, 30].reduce(
    (best, f) =>
      Math.abs(f - (input.flaps ?? state.flap)) <
      Math.abs(best - (input.flaps ?? state.flap))
        ? f
        : best,
    0,
  );
  state.flap = approach(state.flap, targetFlap, 20, dt);
  const rollInput = clamp(input.roll ?? 0, -1, 1);
  const pitchInput = clamp(input.pitch ?? 0, -1, 1);
  const rudder = clamp(input.rudder ?? 0, -1, 1);
  const gust =
    Math.sin((state.time + env.seed) * 1.73) * env.gustSpeed +
    Math.sin((state.time + env.seed) * 5.11) * env.turbulence * 2;
  const wind = Math.max(0, env.windSpeed + gust);
  const relativeWind = ((env.windDirection - state.heading) * Math.PI) / 180;
  const headwind = Math.cos(relativeWind) * wind;
  const crosswind = Math.sin(relativeWind) * wind;

  state.bank = clamp(
    state.bank + (rollInput * 28 - state.bank * 1.7) * dt,
    -60,
    60,
  );
  const turnRate =
    state.airspeed > 20
      ? (1091 * Math.tan((state.bank * Math.PI) / 180)) /
        Math.max(state.airspeed, 20)
      : 0;
  state.heading = normalizeDegrees(
    state.heading + (turnRate + rudder * 3) * dt,
  );
  state.pitch = clamp(
    approach(state.pitch, pitchInput * 12 + (state.onGround ? 0 : 2), 18, dt),
    -15,
    20,
  );

  const liftFactor =
    clamp((state.airspeed - STALL_SPEED) / 25, 0, 1.35) *
    (1 + state.flap / 150);
  const drag =
    0.008 * state.airspeed +
    (state.flap / 30) * 0.22 +
    Math.abs(state.bank) * 0.003;
  const thrustAccel = state.throttle * 9;
  const pitchDrag = Math.max(0, state.pitch) * 0.18;
  state.airspeed = clamp(
    state.airspeed +
      (thrustAccel - drag - pitchDrag - Math.max(0, 0.55 - liftFactor) * 3) *
        dt,
    0,
    160,
  );
  const commandedVS =
    (state.pitch - 2) * 95 +
    (liftFactor - 0.85) * 420 -
    state.bank * state.bank * 0.08;
  state.verticalSpeed = approach(state.verticalSpeed, commandedVS, 900, dt);
  if (state.airspeed < STALL_SPEED && !state.onGround)
    state.verticalSpeed = Math.min(
      state.verticalSpeed,
      -900 + state.airspeed * 8,
    );

  state.groundSpeed = Math.max(0, state.airspeed - headwind);
  state.x +=
    Math.cos(((state.heading - env.runway.heading) * Math.PI) / 180) *
    state.groundSpeed *
    1.68781 *
    dt;
  state.y +=
    (Math.sin(((state.heading - env.runway.heading) * Math.PI) / 180) *
      state.groundSpeed +
      crosswind) *
    1.68781 *
    dt;
  state.distanceTravelled += state.groundSpeed * 1.68781 * dt;
  state.altitudeAGL += (state.verticalSpeed / 60) * dt;
  state.time += dt;

  if (!state.onGround && state.altitudeAGL <= 0) {
    state.altitudeAGL = 0;
    state.onGround = true;
    state.touchdown = {
      time: state.time,
      airspeed: state.airspeed,
      verticalSpeed: state.verticalSpeed,
      bank: state.bank,
      x: state.x,
      y: state.y,
    };
    const unsafe =
      Math.abs(state.verticalSpeed) > 950 ||
      Math.abs(state.bank) > 28 ||
      state.airspeed < 35 ||
      Math.abs(state.y) > env.runway.width;
    state.crashed = unsafe;
    state.phase = unsafe ? "crashed" : "landed";
  }
  if (state.onGround) {
    const braking = clamp(input.brake ?? 0, 0, 1);
    state.airspeed = Math.max(0, state.airspeed - (3 + braking * 18) * dt);
    state.groundSpeed = state.airspeed;
    state.verticalSpeed = 0;
    state.pitch = approach(state.pitch, 0, 12, dt);
    if (
      state.x > env.runway.length + 100 ||
      Math.abs(state.y) > env.runway.width
    ) {
      state.crashed = true;
      state.phase = "crashed";
    }
  } else if (state.altitudeAGL < 60 && state.verticalSpeed < -50)
    state.phase = "flare";
  else if (state.altitudeAGL < 1200) state.phase = "approach";
  state.altitudeMSL = env.runway.elevation + state.altitudeAGL;
  state.stallWarning = !state.onGround && state.airspeed <= STALL_HORN_SPEED;
  return state;
}

export function frameFromState(state: FlightState): TelemetryFrame {
  const { distanceTravelled, touchdown, crashed, ...frame } = state;
  return frame;
}

export function evaluateLanding(
  state: FlightState,
  env: GameEnv = createEnv(),
): LandingResult {
  const touchdown = state.touchdown ?? {
    airspeed: state.airspeed,
    verticalSpeed: state.verticalSpeed,
    bank: state.bank,
    x: state.x,
    y: state.y,
    time: state.time,
  };
  const headingError = Math.abs(
    signedAngle(state.heading - env.runway.heading),
  );
  const centerlineOffset = Math.abs(touchdown.y);
  const sink = Math.abs(touchdown.verticalSpeed);
  const speedError = Math.abs(touchdown.airspeed - TOUCHDOWN_SPEED_IDEAL);
  const verticalSpeed = Math.round(
    clamp(100 - Math.max(0, sink - 100) / 7, 0, 100),
  );
  const airspeed = Math.round(clamp(100 - speedError * 7, 0, 100));
  const alignment = Math.round(
    clamp(100 - headingError * 5 - Math.abs(touchdown.bank) * 2, 0, 100),
  );
  const centerline = Math.round(clamp(100 - centerlineOffset * 2.5, 0, 100));
  const runway = Math.round(
    clamp(
      100 -
        (Math.max(0, touchdown.x - env.runway.length * 0.55) /
          Math.max(1, env.runway.length)) *
          180 -
        (state.crashed ? 100 : 0),
      0,
      100,
    ),
  );
  const total = Math.round(
    verticalSpeed * 0.35 +
      airspeed * 0.2 +
      alignment * 0.2 +
      centerline * 0.15 +
      runway * 0.1,
  );
  const crashed =
    state.crashed ||
    sink > 950 ||
    touchdown.x < -20 ||
    touchdown.x > env.runway.length ||
    centerlineOffset > env.runway.width / 2;
  const quality: LandingQuality = crashed
    ? "crash"
    : total >= 92 && sink < 180 && speedError <= 4
      ? "greaser"
      : total >= 75
        ? "good"
        : total >= 55
          ? "firm"
          : "hard";
  return {
    quality,
    score: {
      total: crashed ? 0 : total,
      verticalSpeed,
      airspeed,
      alignment,
      centerline,
      runway,
    },
    touchdownSpeed: Math.round(touchdown.airspeed),
    verticalSpeed: Math.round(touchdown.verticalSpeed),
    bank: Math.round(touchdown.bank * 10) / 10,
    centerlineOffset: Math.round(centerlineOffset * 10) / 10,
    headingError: Math.round(headingError * 10) / 10,
    stoppingDistance: Math.max(0, Math.round(state.x - touchdown.x)),
    message: QUALITY_BLURBS[quality],
  };
}
